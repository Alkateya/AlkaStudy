# AlkaStudy 1.0.0

Primeira versão estável do AlkaStudy, aplicativo desktop offline de revisão espaçada, organização de baralhos e gamificação dos estudos.

## Destaques

- funcionamento offline e armazenamento local;
- baralhos criados manualmente ou importados em TXT/CSV;
- conteúdo com negrito, marca-texto, código e quebras de linha;
- avaliações De novo, Difícil, Bom e Fácil com próxima revisão persistente;
- XP, 100 níveis, quatro ritmos diários e dez troféus;
- temas claro e escuro com identidade visual AlkaStudy;
- distribuição instalável e portátil para Windows.

## Observações

- A importação APKG ainda não integra esta versão.
- Os dados não possuem sincronização ou backup automático.
- O Windows pode mostrar um aviso do SmartScreen porque o aplicativo ainda não possui assinatura digital.
